# Automatic cookie cutters
> Original code by mrbenbritton @ https://www.thingiverse.com/thing:33096
- I updated the openscad file for newer versions (using AI) and added this Readme

## Inkscape walkthrough:
    1. Text in correct font
    2. "Path" > "Object to Path"
    3. Flip *H*orizontal
    4. "Edit Paths"-Tool > select object => "Extensions" > "Modify Path" > "Flatten Beziers..." (<1)
    5. make sure path is directly under "CC"
    6. Save as inkscape svg for editing + as dxf (R12) for openscad
